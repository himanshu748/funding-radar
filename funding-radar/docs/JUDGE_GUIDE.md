## Take a short tour

Use Node.js 22 or newer. Clone the [public repository](https://github.com/himanshu748/funding-radar), then open the saved workspace:

```sh
git clone https://github.com/himanshu748/funding-radar.git
cd funding-radar
npm ci --ignore-scripts
FUNDING_RADAR_LIVE=0 BOUNTY_POOL_LIVE=0 node --import tsx funding-radar/src/server.ts
```
